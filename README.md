How many browser tabs do I have open? **214** — my honest count, written as one number, digits only, to `/output/entry.txt`.

Three browser windows that have been accumulating for months: research tabs never closed, docs meant to be read, half-finished shopping, a dozen "read later" articles from last year, and the tabs kept open just because closing them feels like losing the thought. A real, lived-in tab-hoarder count — big enough to surprise, small enough to be true.

## Run it

```sh
node main.ts
```

Writes `214` (3 bytes, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to `/output/entry.txt`. Deterministic: no clock, no network, no randomness, no environment input — every run writes the exact same bytes.
